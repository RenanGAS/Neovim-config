## Comandos

#### Normal mode

- `%`: cria arquivo
- `d`: cria diretório
- `<leader>fg`: busca por arquivos git
- `<leader>ff`: busca por arquivos por nome
- `<leader>fs`: busca por arquivos por conteúdo
- `=ap`: para identação de arquivos lua
- `<leader>p`: colar cópia em visual mode sem perder ela
- `<leader>y`: copiar para área de transferência
- `<leader>s`: substituir palavra em que o cursor está
- `<C-W> w`: para trocar de janela
- `<C-W> s` / `<C-W> v`: para abrir uma janela em baixo/à direita
- `<SHIFT-v>`: para selecionar uma linha inteira (de qualquer posição que estiver na linha)
- `<leader>t`: para abrir o terminal
- `<C-\\><C-n>`: para sair do modo terminal
- `<C-o>`: volta para estado anterior
- `<C-]>`: vai para definição de função ou origem de arquivo

#### Cmd

- `:Ex`: volta para explorador de arquivos
- `:m .-2`: move linha para cima
- `:so` or `:source`: para salvar mudanças em um arquivo de configuração
- `:PackerSync`: para instalar/atualizar pacotes recém adicionados com o comando `:so`
- `:terminal`: para abrir um terminal

## Remaps

- `<leader>`: tecla espaço
- `<leader>pv`: volta para explorador de arquivos
